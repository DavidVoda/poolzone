# Product Description Generator — Manual

This document defines how to use AI to generate product descriptions for the Poolzone e-shop. It covers what input to gather, where to find it, and how the final description should be structured.

---

## 1. Purpose

Generate high-quality, accurate, and SEO-friendly product descriptions for pool-related products sold on the Poolzone e-shop. Descriptions must be informative, consistent in tone, and targeted at end customers (pool owners, installers, and maintenance professionals).

---

## 2. Input Sources

Collect as much of the following information as possible before generating a description. The more sources are available, the better the output.

### 2.1 Existing Product Data
- Product name
- Brand / manufacturer
- Model number / SKU
- Category (e.g. pumps, filters, chemicals, accessories)
- Technical specifications (power, dimensions, flow rate, material, certifications, etc.)
- Price / variant options (if relevant to the description context)
- Existing short description or bullet points (if any)

### 2.2 PDF Manuals / Datasheets
- Download any available product manual or datasheet (PDF)
- Extract key sections: features overview, technical specs, installation notes, safety warnings, compatibility information
- Note any highlighted selling points or unique technology names mentioned by the manufacturer

### 2.3 Online Sources
- Official manufacturer website (product page, press releases)
- Distributor or retailer pages for comparable listings
- YouTube videos or review articles (for feature highlights and common use cases)
- Competitor listings (to understand market positioning)

> When using online sources, always verify that the information matches the specific model/variant being described. Do not copy text verbatim — synthesize and rewrite.

---

## 3. Information to Extract

For each product, aim to identify and note down:

| Field | Notes |
|---|---|
| Core function | What does the product do? |
| Key features | Top 3–5 selling points |
| Technical specs | Dimensions, power, capacity, material, certifications |
| Compatible products | Works with which pool sizes, filter types, accessories |
| Installation notes | Any notable setup requirements or constraints |
| Warranty | Duration and coverage (if available) |
| Target user | Beginner pool owner vs. professional installer? |

## 4. Description Template

The description is written in **Czech** and consists of the following sections in this exact order. Use emojis as visual markers for each section heading. Total length should be approximately **800–1000 words** of descriptive content.

---

### 4.1 One-sentence Product Summary

A single introductory sentence that captures the product's core value proposition. Mention the key technology or standout feature, the primary benefit (e.g. energy savings, quiet operation), and the intended pool size or use case.

**Example:**
> Čerpadlo Mr. Pump ECO DE10 je invertorové čerpadlo s plynulou regulací výkonu, které zajišťuje tichý provoz a výrazné úspory energie pro středně velké bazény.

---

### 4.2 🔧 [Primary Feature Heading — e.g. Intelligent Power Control]

Explain the core technical capability that differentiates this product. Use **bullet points** for individual feature details, then close the section with a benefit statement introduced by ➡️.

```
🔧 [Feature Name]

• [Specific capability or parameter — e.g. regulation range, automation feature]
• [Another capability]
• [Another capability]

➡️ [One sentence outcome/benefit for the customer]
```

---

### 4.3 ⚙️ Advanced Functions

List additional smart or practical functions using ✔ checkmarks. Close with a ➡️ benefit statement.

```
⚙️ Pokročilé funkce

✔ [Function 1 — e.g. self-priming, timer modes]
✔ [Function 2]
✔ [Function 3]
✔ [Function 4]
✔ [Function 5]

➡️ [One sentence outcome/benefit]
```

---

### 4.4 🛡️ Safety & Protection

List all built-in safety and protection mechanisms using ✔ checkmarks. Close with a statement about long-term reliability.

```
🛡️ Bezpečnost a ochrana

✔ [Protection type 1 — e.g. overheating, undervoltage]
✔ [Protection type 2]
✔ [Protection type 3]
✔ [Protection type 4]

➡️ [One sentence about durability/reliability]
```

---

### 4.5 🔌 Installation & Operation

List key installation and operational parameters as bullet points (not checkmarks). Include values where known: suction head, pipe diameter, operating temperature range, IP rating.

```
🔌 Instalace a provoz

• Maximální sací výška: [value]
• Průměr potrubí: [value]
• Rozsah provozní teploty: [value]
• Krytí: [IP rating]
• [Any other relevant installation note]
```

---

### 4.6 🏊 Ideal Usage

Describe who this product is ideal for and in which scenarios. Use bullet points or a short paragraph. Mention pool size range, user type (residential/professional), and compatibility with automation or smart systems if applicable.

```
🏊 Ideální využití

• [Use case 1 — e.g. residential pools of X–Y m³]
• [Use case 2 — e.g. users focused on energy savings]
• [Use case 3 — e.g. pools with automation/smart home systems]
```

---

### 4.7 🟢 How It Works (Technical Product Description)

A short paragraph (3–5 sentences) describing the operating principle — how the product performs its function step by step. Written in plain language, accessible to a non-expert reader.

---

### 4.8 🟢 Technical Specifications

A bulleted list of all key technical parameters with values. Include all that are available from the datasheet or manufacturer specs.

```
🟢 Technické parametry — [Model name]

• Objem bazénu: [value]
• Příkon: [value]
• Napájení: [value]
• Proud: [value]
• Průtok (max): [value]
• Dopravní výška (max): [value]
• [Other parameters as available]
```

---

### 4.9 🟢 FAQ

Include 4–6 frequently asked questions and answers relevant to the product. Questions should reflect real customer concerns: compatibility, sizing, noise, automation, failure handling. Format as `**Q:** ... **A:** ...`

```
🟢 Časté dotazy

**Jak velký bazén toto čerpadlo pokryje?**
[Answer]

**[Next question?]**
[Answer]

[Continue for 4–6 Q&A pairs]
```

---

### Template Notes

- Never include pricing, stock availability, or delivery information in the description.
- If a specification is not available from any source, omit it — do not guess or invent values.
- Emoji section icons should be consistent across all products (use the same emoji for the same section type).
- The FAQ section should be tailored per product — do not reuse generic questions that don't apply.
- The template in Section 4.1–4.9 is designed for **pumps**. For other product categories use the alternate templates below.

## 4B. Alternate Template — Elektrolýza / Solonizační jednotky

Use this template for salt chlorinators and electrolysis units instead of the pump template in Sections 4.2–4.9. The section order, emojis, and bullet style all differ from the pump template.

### Section overview

| Section | Emoji | Style |
|---|---|---|
| Key benefits | ⭐ | ✅ bullet list, 5–7 items |
| Detailed description | 📖 | 2–4 narrative paragraphs |
| Technical specs | ⚙️ | Bullet list with values |
| Package contents | 📦 | Bullet list of included items |
| Safety & warnings | ⚠️ | Bullet list |
| FAQ | ❓ | 5–8 Q&A pairs |

---

### 4B.1 ⭐ Hlavní benefity

Lead with 5–7 concise ✅ bullet points summarising the top customer benefits — what the product automates, what it replaces, and what it simplifies.

```
⭐ Hlavní benefity

✅ [Primary automation feature — e.g. Automatická dezinfekce vody pomocí elektrolýzy soli]
✅ [What the user no longer has to do — e.g. Bez nutnosti ručního dávkování chloru]
✅ [Adjustability or control — e.g. Nastavitelný výkon chlorace (0–10 úrovní)]
✅ [Self-maintenance feature — e.g. Samočisticí cela díky automatické reverzi polarity]
✅ [Special mode — e.g. Režim BOOST pro rychlé vyčištění vody]
✅ [Ease of installation]
✅ [Economy / running cost benefit]
```

---

### 4B.2 📖 Detailní popis

2–4 paragraphs of narrative. Suggested paragraph structure:

- **Paragraph 1:** What the product is + core technology + pool size suitability + primary output spec (e.g. chlorine production g/h).
- **Paragraph 2:** Adjustable settings, special modes (e.g. BOOST), self-cleaning mechanism (polarity reversal).
- **Paragraph 3:** Operating requirements — salt concentration, water flow dependency, IP rating, installation position.

---

### 4B.3 ⚙️ Technické parametry

Bullet list of all parameters available from the datasheet. Use Czech parameter names.

```
⚙️ Technické parametry

• Typ zařízení: [e.g. solonizační jednotka — elektrolýza soli]
• Doporučený objem bazénu: [value m³]
• Produkce chlóru: [value g/h]
• Napájení: [voltage V]
• Nastavení výkonu: [range, e.g. 0–10]
• Krytí: [IP rating]
• Připojení: [pipe diameter mm]
• Maximální tlak: [value bar]
• Životnost elektrody: [hours]
• [Additional parameters as available]
```

List all items included in the box.

```
📦 Obsah balení

• [Item 1 — e.g. Řídicí jednotka]
• [Item 2 — e.g. Elektrolytická cela s elektrodami]
• [Item 3 — e.g. Propojovací kabel]

### 4B.5 ⚠️ Upozornění a bezpečnost

List all safety and installation warnings as bullets. Always include the most critical constraints (water flow, salt concentration, installation position).

```

## 5. Tone & Style Guidelines

- **Language:** Czech (primary), unless specified otherwise
- **Tone:** Professional but approachable; avoid overly technical jargon unless the product demands it
- **Length:** Follow the structure defined in Section 4
- **Do not include:** Pricing, delivery times, stock status, or any time-sensitive information
- **Do not fabricate:** If a specification is unknown, omit it rather than guess

## 5.5 Input & Output Files

### Input file — Upgates export XML

Location: `descriptionGenerator/poolzoneData/<export-filename>.xml`

This is a standard Upgates product export. The generator reads these fields from each `<PRODUCT>`:

| XML field | Used for |
|---|---|
| `<CODE>` (direct child) | Product identifier in the output |
| `<DESCRIPTIONS><DESCRIPTION language="cz"><TITLE>` | Product name passed to Claude |
| `<DESCRIPTIONS><DESCRIPTION language="cz"><SHORT_DESCRIPTION>` | Existing short description (context) |
| `<DESCRIPTIONS><DESCRIPTION language="cz"><LONG_DESCRIPTION>` | Existing long description (context) |
| `<MANUFACTURER>` | Manufacturer name |
| `<PARAMETERS><PARAMETER>` | Technical parameters (name + value pairs, language="cz") |
| `<FILES><FILE><URL>` (`.pdf` only) | PDF manuals / datasheets for additional context |

Export the file from Upgates admin → Products → Export (XML format, version 2.0).

### Output file — Upgates import XML

Location: `descriptionGenerator/output/descriptions_import.xml`

A **minimal** Upgates-compatible import file. It contains only the fields necessary to update descriptions — no prices, stock, images, or any other data. This minimises the risk of accidentally overwriting unrelated product fields during import.

```xml
<?xml version="1.0" encoding="UTF-8"?>
<PRODUCTS version="2.0">
  <PRODUCT>
    <CODE>410005</CODE>
    <DESCRIPTIONS>
      <DESCRIPTION language="cz">
        <SHORT_DESCRIPTION><![CDATA[Plain text 2–3 sentence summary.]]></SHORT_DESCRIPTION>
        <LONG_DESCRIPTION><![CDATA[<p>Full HTML description...</p>]]></LONG_DESCRIPTION>
      </DESCRIPTION>
    </DESCRIPTIONS>
  </PRODUCT>
  ...
</PRODUCTS>
```

Import this file via Upgates admin → Products → Import. Upgates will match products by `<CODE>` and update only `SHORT_DESCRIPTION` and `LONG_DESCRIPTION`.

**Progress saving:** The script saves progress every 10 products so a crash or rate-limit interruption does not lose completed work.

## 6. Generation Workflow

### Automated batch generation (script)

Use `generate_descriptions.py` to process an entire category at once:

```bash
# 1. Install dependencies
pip install -r requirements.txt

# 2. Set your Anthropic API key
export ANTHROPIC_API_KEY=sk-ant-...

# 3. Run
python descriptionGenerator/generate_descriptions.py
```

The script will:
1. Parse the export XML from `descriptionGenerator/poolzoneData/`
2. For each product, call Claude (claude-sonnet-4-6) with all available data
3. Download and extract text from any PDF manuals linked in the export (cached per URL)
4. Save progress every 10 products to `descriptionGenerator/output/descriptions_import.xml`
5. Print progress: `[N/total] Processing CODE — TITLE …`

Import the output file via **Upgates admin → Products → Import**.

### Manual single-product generation

Follow these steps when generating a description for a single product:

1. Collect all available input (Section 2)
2. Extract and note key information (Section 3)
3. Identify gaps — what is missing or unclear?
4. If a PDF is available, extract relevant content from it
5. If online sources are available, research and synthesize
6. Generate the description using the template in Section 4
7. Review: check for accuracy, completeness, and tone consistency
8. Output the final description ready to paste into the e-shop CMS

## 8. Notes & Edge Cases

- **Products with no PDF or online presence:** Work only from existing product data. Flag the description as needing review.
- **Multiple variants (e.g. different sizes/powers):** Generate a base description and note variant-specific differences separately.
- **Chemicals:** Always include relevant safety or handling notes where applicable.
- **OEM / rebranded products:** The original manufacturer's documentation may be more detailed — check both brand names.
